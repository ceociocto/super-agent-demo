## 复核发现与修复

1. **批准请求可省略版本号**：修复为 approve/reject 必填正整数 expectedRevision；缺失 400，过时 409。前端在产物页才提供批准，并提交已显示版本。
2. **跟进时上一稿正文丢失**：完整草案保存为 assistant 消息；模型下一轮带入同任务用户输入和历次草案。新增测试验证重启后仍找得到全文，且不同任务不串内容。
3. **模型默认名时效**：主 agent 核验当前官方 API 文档后，将过时默认名改为 deepseek-flash，并显式禁用思考模式；假请求测试验证参数。
