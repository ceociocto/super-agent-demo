# 个人多任务助理：分阶段交付

本版直接连接可配置的 OpenAI 兼容 API，不依赖 Hermes、DeepSeek Harness 或 Colima。演示用例使用同一套通用工具循环，不写死业务场景。

| 阶段 | 交付 | 验收 | 状态 |
| --- | --- | --- | --- |
| 1 | 模型配置、真实工具调用循环、本机文件与异步命令工具 | 协议/取消/工具测试，真实模型读取随机证据并回答 | 已验证并提交 |
| 2 | Router、多 Worker、Conversation/Task/Run、持久化及跟进 | 同聊天并发、任务关联、停止、恢复及副作用记录 | 已验证并提交 |
| 3 | 网页、CLI、stdio MCP | 多入口操作同一任务，真实执行记录与产物可见 | 待实现 |
| 4 | 六个演示用例、部署说明与实测证据 | 真实模型/工具验证与回归，明确未验证边界 | 待实现 |

各阶段通过验收后分别提交并推送到 `codex/personal-multitask-assistant`。不把协议测试替身当成真实模型验证，不把历史 v2 演示数据当成新版本执行结果。

## 六个用例

1. 自由 GitHub 请求：Router 派工，Worker 自行调查、修改、测试并交付。
2. 两项任务并发，长命令后台完成后回到执行会话。
3. 总聊天或任务详情补充要求，原任务续办。
4. 长日志保存为文件，模型按引用和分页读取历史证据。
5. 停止、失败或服务重启后保留 Task，并建立新 Run 继续；核对已发生的外部操作。
6. 网页与 MCP/CLI 操作同一套任务和消息。

首版为本机个人助理。工作目录用于防止并发编辑混杂，不是操作系统权限隔离。实际文件、GitHub、命令操作沿用当前用户权限。普通任务直接交付，缺信息时等待输入。
